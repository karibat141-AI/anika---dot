ANIKA — Telegram AI Bot

ANIKA — Telegram-бот с искусственным интеллектом, который отвечает пользователям на вопросы и помогает общаться с ИИ прямо в Telegram.

Возможности

- Ответы на сообщения пользователей с помощью ИИ
- Общение в формате диалога
- Команда "/start"
- Работа через Telegram
- Запуск на облачном сервере Render

Технологии

- Python
- Telegram Bot API
- OpenAI API
- Render
- GitHub

Цель проекта

Создать простого и удобного AI-помощника, доступного пользователям прямо в Telegram.

Проект находится в разработке.
